# Web Scraper for Headlines

## Description

A Python-based web scraper that fetches news headlines from a website, extracts titles and URLs, and stores the results in CSV and JSON formats.

## Features

* Fetch headlines from a news website
* Extract headline titles and URLs
* Save results to CSV
* Save results to JSON
* Keyword-based filtering
* Error handling using try-except
* Delay between requests using time.sleep()

## Technologies Used

* Python
* Requests
* BeautifulSoup
* CSV
* JSON

## How to Run

1. Install required libraries:

pip install requests beautifulsoup4

2. Run the program:

python web_scraper.py

3. Enter a keyword or press Enter to fetch all headlines.
